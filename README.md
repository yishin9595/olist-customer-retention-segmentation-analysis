## 專案內容
本專案使用 Kaggle 公開的巴西電商資料集，並透過 RFM 分析進行顧客分群，分析顧客價值與活躍程度，並提供對應的行銷建議

## 商業問題
如何根據顧客的最近購買時間、購買頻率與消費金額進行分群，並提供留存與喚回實際行銷建議

## 資料集
使用 Kaggle 公開的巴西電商資料集，資料包含訂單、顧客、付款與商品相關資訊

## 分析方法
本專案使用 RFM 分析，從三個面向評估顧客價值：

- Recency：顧客最近一次購買離至今多久
- Frequency：顧客購買的頻率
- Monetary：顧客累積消費金額

每顧客在三個指標上都會被給 1 到 5 分的分數

- Recency 分數越高，代表顧客越近期有購買
- Frequency 分數越高，代表顧客購買次數越多
- Monetary 分數越高，代表顧客消費金額越高

## 顧客分群

### 高價值顧客

Recency、Frequency、Monetary 分數皆高的顧客

建議行動：
- 透過會員制度維持互動
- 提供專屬優惠
- 建立關聯商品推薦

### 潛在流失顧客

Frequency 或 Monetary 分數高，但 Recency 分數低的顧客

建議行動：
- 執行顧客喚回活動
- 提供針對性折扣
- 了解顧客近期未回購的可能原因

### 低價值顧客

Frequency 與 Monetary 分數較低的顧客

建議行動：
- 使用低成本行銷管道觸及並觀察後續回購行為

## 主要結論

RFM 分析可以協助判斷哪些顧客值得優先投入留存與喚回資源，相較於對所有顧客採取相同行銷策略，可以根據顧客價值與近期活躍程度，更有效率分配行銷資源
