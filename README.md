# Olist Customer Retention & Segmentation Analysis

## 專案背景

本專案使用 Kaggle 公開的 Brazilian E-Commerce Public Dataset by Olist，原本以 RFM 分析進行顧客分群，但在觀察 Frequency 分布後發現多數顧客只購買一次，
因此將分析重點從 RFM 分群轉向顧客留存與回購行為。


## 商業問題

顧客主要流失在哪個購買階段？如何根據回購行為建立可執行的顧客分群，以建議後續的留存與喚回策略？

分析拆成四個問題：

1. 顧客的回購情況如何？
2. 顧客主要流失在哪個購買階段？
3. 成功回購的顧客通常多久完成第二購？
4. 如何根據這些行為建立可執行的顧客分群？


## 1. 每位顧客購買次數分布

- 約 96.96% 顧客只購買 1 次
- 只有約 3.04% 顧客完成至少 2 次購買

## 2. 90 天回購率

由於越晚首次購買的顧客，可被觀察是否回購的時間越短，直接比較不同月份的回購率可能低估後期顧客的回購表現，
因此統一使用首購後 90 天作為觀察期間，並排除沒有完整 90 天觀察期的顧客。

- 多數月份的 90 天回購率約為 2%，確認存在低回購


## 3. 顧客主要流失在哪個購買階段？

| 購買階段 | 下一購比例 |
| --- | ---: |
| 第 1 購 → 第 2 購 | 3.04% |
| 第 2 購 → 第 3 購 | 8.18% |
| 第 3 購 → 第 4 購 | 20.34% |

最大的顧客流失發生在：第一次購買 → 第二次購買


## 4. 第二購通常何時發生？

| 首購至第二購間隔 | 顧客占比 |
| --- | ---: |
| 0–30 天 | 50.80% |
| 31–60 天 | 10.74% |
| 61–90 天 | 6.83% |
| 91–180 天 | 14.59% |
| 180 天以上 | 17.05% |

- 完成第二購的顧客中，約 50% 在首購後 30 天內完成第二購
- 首購後前 30 天可作為優先測試促進第二購活動的時間


## 5. 顧客分群

根據上方分析結果，建立四個以行為為基礎的顧客分群：

| 分群 | 定義
| --- | ---
| 新客 | 只購買 1 次，首購距資料截止日 ≤ 30 天
| 未回購顧客 | 只購買 1 次，首購距資料截止日 > 30 天
| 活躍回購客 | 購買 ≥ 2 次，距最後購買 ≤ 180 天
| 非活躍回購客 | 購買 ≥ 2 次，距最後購買 > 180 天

- 歷史資料中，81.47% 的再次購買發生在上一筆購買後 180 天內，因此以 180 天作為活躍與非活躍回購客的參考門檻


## 6. 分群商業價值

| 分群 | 顧客占比 | 營收占比 | 人均累積消費 |
| --- | ---: | ---: | ---: |
| 未回購顧客 | 91.26% | 88.99% | 161.56 |
| 新客 | 5.70% | 5.36% | 155.80 |
| 非活躍回購客 | 1.75% | 3.16% | 298.90 |
| 活躍回購客 | 1.29% | 2.50% | 321.36 |

- 回購顧客合計只占約 3.04%，但貢獻約 5.66% 的歷史營收
- 活躍與非活躍回購客的人均累積消費，都明顯高於只購買一次的顧客


## 主要結論

1. 第二購促進
   - 首購後前 30 天可作為優先測試第二購促進策略的時間
   - 可推動個人化推薦、第二購優惠或提醒機制

2. 回購客留存
   - 維持近期仍有購買行為的回購顧客
   - 可測試會員制度與個人化推薦

3. 非活躍回購客喚回
   - 針對曾回購但超過 180 天未購買的顧客
   - 推動專屬優惠與喚回活動
